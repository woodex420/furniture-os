# Unsupported historical spreadsheet import

The old demo import page is retained for reference only and is not built or deployed. Its `xlsx` parser had high-severity advisories and no npm fix in the inherited version; the dependency and upload functionality were removed. Do not reactivate this page or treat it as an approved Furniture import. A future import needs an independently selected, maintained parser and tested limits, validation, authorization, privacy, duplicate handling, audit and rollback. The Laravel CRM remains the intended authority.
