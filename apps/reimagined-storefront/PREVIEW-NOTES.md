# Reimagin v1 storefront integration preview

Frontend snapshot from `blackibexofficial-blip/woodex-reimagined`, commit `e8502b0d9c376a985b50ff610ed1d6019b6449a0`. On inspection the upstream `main` commit `5123af95643404649901d753eb8b4e8384c8b969` was two commits ahead and changed only `roadmap.md`; it did not contain newer frontend code. This isolated copy has local preview and integration adaptations, and does not include upstream environment files.

Port 5174 serves this React/Vite/Tailwind frontend, replacing the older `woodex-2030` preview process. The previous source was not deleted. Port 5176 is the separate Furniture Laravel admin. The actual Reimagin homepage reads the first hero slide's title, subtitle, order, button and bundled/uploaded background, plus the tagline beneath it, from `/storefront-api/home`. The Vite server proxies that relative path to isolated Laravel; the browser does not call sandbox localhost. Connected components recheck while visible and retain fallback content if the endpoint is unavailable. Other storefront sections and features are not integrated yet.

Furniture admin's Website Studio → Site Overview is an owner-only, feature-flagged editor with an actual-storefront canvas for these fields and revision restore. Updates are immediately available from the API, and the visible React preview polls them; this is **not** the requested full visual page builder, real-time collaborative editor, multi-page CMS, public deployment, crawler-visible immediate publishing, or a complete Laravel storefront integration. The previous Puck demo editor and lab routes are no longer exposed in this preview so they cannot be mistaken for an editor of the real homepage; their source is retained. Existing catalogue and marketing content is reference/demo content and has not been verified as current business data. Do not send real orders or messages through the preview.

The preview's configuration uses its own SQLite database, sample records and demo credentials. It is not Hostinger and may be reset. The home editor is off by default outside the synthetic preview (`FURNITURE_HOME_EDITOR_ENABLED=false`). MySQL migrations/locking, access policy, safe rollout, backup and the remaining frontend/backend contracts require review before any hosted use.

Build verification is `npx vite build`. The upstream `npm run build` invokes Bun and sitemap scripts not included in this frontend-only snapshot. The inherited TypeScript check has known Supabase adapter/schema errors; a Vite build alone does not prove the entire source is production-ready.
