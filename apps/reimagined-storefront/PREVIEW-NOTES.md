# Reimagin v1 storefront integration preview

Frontend snapshot from `blackibexofficial-blip/woodex-reimagined`, commit `e8502b0d9c376a985b50ff610ed1d6019b6449a0`. On inspection the upstream `main` commit `5123af95643404649901d753eb8b4e8384c8b969` was two commits ahead and changed only `roadmap.md`; it did not contain newer frontend code. This isolated copy has local preview and integration adaptations, and does not include upstream environment files.

Port 5174 now serves this React/Vite/Tailwind frontend, replacing the older `woodex-2030` preview process. The previous source was not deleted. Port 5176 is the separate Furniture Laravel admin. The original Reimagin homepage remains the rendered page: only its first hero title and subtitle can be read from the Furniture API at `/storefront-api/home`. In the preview the Vite server proxies that relative path to the isolated Laravel service; the browser does not call sandbox localhost. The homepage rechecks for changes every 2.5 seconds while visible and keeps the original text if the endpoint is unavailable. Other storefront features are not integrated yet.

Furniture admin's Website Studio → Site Overview is an owner-only, feature-flagged form that saves those two fields. Updates are immediately available from the API; this is **not** the requested full visual page builder, real-time collaborative editor, multi-page CMS, public deployment, or a complete Laravel storefront integration. The previous Puck demo editor and lab routes are no longer exposed in this preview so they cannot be mistaken for an editor of the real homepage; their source is retained. Existing catalogue and marketing content is reference/demo content and has not been verified as current business data. Do not send real orders or messages through the preview.

The preview's configuration uses its own SQLite database, sample records and demo credentials. It is not Hostinger and may be reset. The home editor is off by default outside the synthetic preview (`FURNITURE_HOME_EDITOR_ENABLED=false`). MySQL migrations/locking, access policy, safe rollout, backup and the remaining frontend/backend contracts require review before any hosted use.

Build verification is `npx vite build`. The upstream `npm run build` invokes Bun and sitemap scripts not included in this frontend-only snapshot. The inherited TypeScript check has known Supabase adapter/schema errors; a Vite build alone does not prove the entire source is production-ready.
